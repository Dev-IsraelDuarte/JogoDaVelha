# Jogo da Velha (Tic-Tac-Toe) 🕹️

Este é um projeto de **Jogo da Velha** desenvolvido em **C#** utilizando **Windows Forms**. O projeto implementa a lógica clássica do jogo com suporte para um modo contra o computador (Bot).

![Interface do Jogo](./Captura%20de%20tela%202026-04-27%20071057.png)

## 🚀 Funcionalidades

- **Modo Jogador vs Bot:** Jogue contra uma IA simplificada.
- **Lógica de Vitória:** Verificação automática de linhas, colunas e diagonais.
- **Reset:** Reinicie a partida a qualquer momento.
- **Interface Desktop:** Desenvolvido com WinForms para Windows.

## 🛠️ Estrutura do Projeto

O código está organizado da seguinte forma:

- `Bot.cs`: Contém a lógica de decisão do computador.
- `Game.cs`: Gerencia o estado do tabuleiro e as regras do jogo.
- `Form1.cs`: Controla a interface gráfica e eventos de clique.
- `Enums.cs`: Define os estados dos jogadores e células.
